# LHCC
LHCC_V2 is a custom project im working on in my freetime. It uses real-world radar references for its design.
Our project is still a work in progress, and is not yet finished. It may contain bugs, inaccuracies and unfinished parts.

# Known bugs and unfinished parts
- we are currently in the progress of making custom ground and tower positions and realistic labels for them, but we dont have an ETA on when they will be released.
